# 基于 CBAM 注意力改进 ResNet 的中草药图像细粒度分类

18 类中草药外观相近、纹理差异细微，原始 ResNet 对关键判别区域聚焦不足。
本项目手写实现 CBAM 注意力模块并嵌入 ResNet 残差块，通过消融实验验证其对细粒度分类的增益。

## CBAM 实现

```
        ┌──────────────────────────────────────┐
输入 ──→│  通道注意力                            │
        │  AvgPool ─┐                          │
        │           ├→ 共享 MLP(1×1 Conv) → σ  │──→ × 输入
        │  MaxPool ─┘   (降维 ratio=16 后升维)  │
        └──────────────────────────────────────┘
                          ↓
        ┌──────────────────────────────────────┐
        │  空间注意力                            │
        │  通道维 Mean ─┐                       │
        │               ├→ Concat → 7×7 Conv → σ│──→ × 特征图
        │  通道维 Max  ─┘                       │
        └──────────────────────────────────────┘
```

**通道注意力**：对特征图并行做全局平均池化与最大池化，两路经同一个 1×1 卷积共享 MLP
（先按 ratio=16 降维再升维），相加后过 Sigmoid 得到通道权重。

**空间注意力**：在通道维上分别取均值与最大值，拼接成 2 通道后经 7×7 卷积与 Sigmoid，
得到空间权重。

两者串联作用于特征图，嵌入 `BasicBlock` 与 `Bottleneck` 的残差相加与激活之后
（封装为 `BasicBlock_CBAM`），支持 ResNet34 / 50 / 101 与 ResNeXt 切换做消融对比。

## 训练设置

| | |
|---|---|
| 数据 | 18 类中草药图像，数据增强后按 9:1 划分训练/验证集 |
| 增强 | RandomResizedCrop(224) + 随机水平翻转 + ImageNet 均值方差归一化 |
| 优化器 | Adam，lr=1e-4 |
| 损失 | 交叉熵 |
| 其他 | 按验证准确率保存最优权重，绘制 train/val 的 loss 与 acc 曲线监控过拟合 |

## 消融结果

### 同等 80 epoch 条件下

| | 验证准确率 | 训练损失 |
|---|---|---|
| ResNet34 | 89.1% | 0.491 |
| **ResNet34 + CBAM** | **93.7%** | **0.351** |

准确率提升 4.6 个百分点，训练损失同步下降，收敛更快且更稳定。

### 延长训练至 150 epoch

验证准确率稳定在 **97.4%**，训练损失 0.230，loss 曲线平稳下降无明显震荡。

### 测试集表现（1502 张样本）

| | |
|---|---|
| Accuracy | 93.94% |
| Macro-F1 | 0.9386 |
| Weighted-F1 | 0.9392 |

macro-F1 与 accuracy 几乎相等，说明 **18 个类别的 F1 分布均衡，不存在少数类被牺牲的情况**。
混淆矩阵显示预测结果高度集中在对角线。

## 文件

| 文件 | 说明 |
|---|---|
| `model.py` | CBAM 模块、BasicBlock_CBAM、Bottleneck，以及 ResNet34/50/101 与 ResNeXt 构造函数 |
| `train.py` | 训练主流程，含 loss / acc 曲线绘制 |
| `predict.py` | 单图推理，输出 softmax 全类别概率 |
| `split_data.py` | 按 9:1 划分训练/验证集 |

## 运行

```bash
python split_data.py      # 划分数据集
python train.py           # 训练，产出 ResNet34_cbam.pth 与 class_indices.json
python predict.py         # 单图推理
```

数据集与权重未纳入版本控制，脚本中的路径需按本地实际目录调整。
