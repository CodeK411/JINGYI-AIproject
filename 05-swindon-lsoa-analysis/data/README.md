# Data

Four files. `features.csv` is the only input the models read; everything else is either a
lookup or a generated intermediate.

| File | Shape | Role |
|---|---|---|
| `features.csv` | 1,129 × 83 | The analysis frame: one row per LSOA, all indicators joined |
| `Swindon LSOA local names.xlsx` | 140 × 3 | LSOA code → local place name, Swindon only |
| `Swindon LSOA local names.csv` | 140 × 3 | The same lookup; the `src/` scripts read csv |
| `msoa_features.csv` | 27 × 43 | Swindon aggregated to MSOA, generated by `notebooks/01` |

`features.csv` and the name lookup were unpacked from the packaged Tableau workbooks in
`tableau/` so that the notebooks and scripts run on a clean checkout. The 66 MB ONS
boundary GeoJSON the LSOA dashboard uses stays inside the `.twbx` and is not duplicated
here.

## Keys and geography

| Column | Meaning |
|---|---|
| `LSOA21CD` / `LSOA21NM` | 2021 LSOA code and ONS name — the row key |
| `Local LSOA21 Name` | Local place name (from the lookup), used in every chart |
| `MSOA21CD` / `MSOA21NM` | Parent MSOA — **the cross-validation grouping key** |
| `LSOA11CD` | 2011 code, for joining older published series |
| `RUC21CD` / `RUC21NM` / `Urban_rura` | Rural–urban classification |
| `area_km2`, `Shape__Are`, `Shape_Leng` | Geometry measures |

## Target

`LSOA GVA Estimates (millions)` — present for 1,024 of the 1,129 rows (127 Swindon,
897 comparator). A modelled estimate rather than a measured quantity, and heavily
right-skewed: one area holds 28.8% of Swindon's total. Every model fits `log1p` of it.

## Other columns in the frame

Not in the predictor set, but used by the EDA notebooks, the typology figure and the
dashboards: `total_employees`, `part_time_employees`, `full_time_employees` (absolute job
counts — the typology and the decision tree use these, the Random Forest deliberately does
not); the remaining IMD sub-deciles (`Income_decile`, `Employment_decile`,
`Education_decile`, `AdultSkills_decile`); the full Census 2021 qualification ladder;
`Mid-2024 population`, `Working_Age_Pop`, `Pct_Working_Age`; the 2023 and 2026 VOA
hereditament counts and rateable-value levels; the ten `pct_enterprise_*` turnover bands
and `turnover_diversity_1-HHI_2025_msoa`; `share_enterprises_public_2025_msoa` /
`_private_`; and the two broadband coverage shortfall measures.

## Provenance

Indicators are derived from published UK open data — ONS (mid-year population estimates,
Census 2021 qualifications, December 2021 LSOA and MSOA boundaries), the Valuation Office
Agency (non-domestic rateable values, 2023 and 2026), the English Indices of Deprivation
(2019 deciles), enterprise counts by size and turnover band, Ofcom-derived broadband
coverage, and NaPTAN-derived bus-stop locations. The assembled frame is a research
artefact, not an official statistical release: for anything beyond reproducing this
analysis, go back to the primary sources.
